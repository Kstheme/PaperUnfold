# Deep reading (explicit request)

Keep the same source fidelity and rendering contract as the quick guide. Follow
the requested scope: whole main paper, specific appendices, reproduction
analysis, or selected objects. Read relevant sections and inspect the source
figures/tables/equations used in claims. Explain section roles and method
conditions at the requested depth. Investigate contradictions that affect the
conclusion; mark unresolved issues rather than silently correcting the paper.
Distinguish paper results from actual replication.

Give larger tasks a time estimate and progress updates. Deep mode has no five-
minute target. Reuse the acquired source and existing guide, adding only the
requested depth. Save a separate audit only when requested. Deep content does
not itself require a browser regression suite.

Read [guide-format.md](guide-format.md) for additional visual fields or language
labels. Read [mechanism-interaction.md](mechanism-interaction.md) only when the
researcher requests a mechanism experiment or a variable-based example.
