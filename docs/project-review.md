# PaperUnfold 项目评审与定位记录

更新日期：2026-10-04。用户已确认本轮推荐的命名、语言策略与默认体验。正式产品行为见 [设计方案](design.md)，领域定义见 [术语表](../CONTEXT.md)。

## 已确认定位

- **项目名**：PaperUnfold。推荐仓库 slug 为 `paper-unfold`，当前本地目录仍为 `paper-reading-skills`。
- **英文说明**：Unfold research papers into clear, visual guides.
- **中文说明**：把论文的逻辑展开，把难懂的地方讲清楚。
- **受众**：首发面向全球各学科研究人员，不要求用户跨学科阅读。
- **核心目标**：辅助读者快速建立论文全貌，并按需深入理解。
- **阅读方法**：共用阅读与教学方法，根据论文自身的研究、证据与论证方式适配，无需用户先选择学科模板。
- **讲解起点**：首次导读直接呈现主线，陌生概念按需补充；深入教学时再检查相关前置知识。
- **默认体验**：轻量 HTML 导读、必要图示与按需深入教学。
- **语言**：跟随用户对话语言，显式语言要求优先；关键术语保留原文名称。README 提供英文与中文版本。
- **机制交互**：用户要求，或确实有助于理解当前机制时提供，不作为每篇论文的必需输出。
- **能力入口**：保持 `paper-guide` 与 `paper-tutor` 两个独立 skill。教学可以从原论文直接开始。

## 命名依据

“Unfold”表达把论文中的研究逻辑、概念关系与方法步骤逐层展开，能容纳导读与教学，也不依赖单次热点。

本次命名检索发现 [Paper Unfold 商业科技论坛](https://ekraf.go.id/news-en/minister-of-creative-economy-appreciates-paper-unfold-2025-as-a-platform-for-dialogue-to-address-digital-transformation-challenges) 等非学术用途。用户在获知这一点后选择了 PaperUnfold。该选择不表示名称可以独占使用。

其他候选包括 Paper2Insight 与 Paper2Explore，本次检索未发现同名产品。PaperLens、PaperLoom 和 PaperPrism 已有相关项目或产品，因此没有优先采用。

仓库已有中英文 README、设计方案、[实现规格](spec.md)、术语表、评审记录与原始教学 prompt。两个 skill、HTML 模板、学习进度格式、真实论文示例与安装流程尚未实现。

## 文档调整

README 用项目价值、阅读路径和真实状态介绍项目，再解释两个入口。英文 README 作为主入口，中文版本保持相同能力与状态说明。

设计方案明确了表达方式选择：研究路径用流程图，概念差异用对照表，公式用符号解释和数值例子。主线优先、细节展开，不要求每章生成图示或每篇论文生成交互。方法流程与图表公式按论文实际内容呈现，避免强制套用实验或算法结构。

保留并突出原文证据定位、术语一致、作者陈述与讲解者推断的区分，以及“已讲解”和“已掌握”的区分。导读完成检查与用户理解验证分别进行。

术语表移除了章节导读仅限中文的定义，并补充教学图示与机制交互的含义。术语表只维护领域语言，发布与实现计划保存在设计和评审中。

原始教学 prompt 保持原文供对照。其“未掌握就不允许结束”的要求与最终设计不同，不能直接作为实现规范。实际教学遵循允许用户直接解释、跳过、暂停或结束的设计。

## 实施与发布优先级

1. 实现并验证 `paper-guide` 与轻量 HTML 模板。
2. 实现 `paper-tutor` 与学习进度格式，提供简短教学示例。
3. 准备算法、实证研究、理论或人文论证的代表性论文导读，包含英文与中文输出。
4. 补齐真实截图、原文来源、生成环境、经过验证的安装步骤与许可证。
5. 用相同原文材料对比普通文字解释与 PaperUnfold 导读，说明生成条件。

机制小实验按需提供，不是上述发布路径的前置条件。实际安装、平台支持、读取依赖与 HTML 资源要求在实现时补齐。未验证的能力不列为已支持。

传播素材聚焦一个具体阅读困难与一个可看到的结果，例如“看完方法章节仍不懂步骤如何连接 → 在导读中查看每步的输入、处理与输出”。演示对应真实结果，不以未经测量的时间节省或掌握率作为宣传承诺。

## 已确认的方法论定位

用户进一步明确：受众是全球各学科研究人员，讲解跟随对话语言，并提出阅读能力本质上是方法论、是否可以与学科无关的问题。

已有设计可以复用研究主线梳理、术语澄清、证据定位和按需教学等阅读方法；具体解释仍需尊重论文的研究、证据与论证方式。本文已修正默认要求方法流程、输入输出和图表公式的表述，与已有的论文类型适配原则保持一致。

用户已确认：

1. 使用通用阅读与教学方法，根据论文内容自适应，不要求用户先选择学科模板。
2. 面向研究人员，首次导读直接呈现论文主线，陌生概念按需补充；深入教学时再检查当前问题必需的前置知识。

跨类型示例用于检查通用方法是否带有隐含的学科假设。方法通用不等于不同论文使用相同的证据形式或推理要求，具体解释仍保留专业语境。
