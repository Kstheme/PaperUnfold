## Guide entrypoint and source review

The evaluator supplied `tests/fixtures/attention-excerpt.txt` and asked an
independent agent to read `skills/paper-guide/SKILL.md`, explain in Chinese,
and save HTML. It read the format reference, authored JSON, and invoked the
renderer successfully. The actual output is preserved as
[agent-invocation-zh.html](../../examples/paper-guide/agent-invocation-zh.html)
and [agent-invocation-zh.json](../../examples/paper-guide/agent-invocation-zh.json).
The separately named `attention-excerpt-guide` files are manually authored
renderer examples, not evidence of independent invocation.

The source is a deliberately short excerpt from Vaswani et al.,
[Attention Is All You Need, Sections 3.2/3.2.1](https://arxiv.org/html/1706.03762v7).
The evaluator verified the source passages and formula against that primary
source before making the fixture. Both forward agents were instructed to use
the supplied text only. Manual review of the actual output confirmed:

- The weighted-sum description, Equation (1), and `1/sqrt(d_k)` match the fixture.
- Evidence quotations occur literally in the supplied input; observed sections
  and equation labels are used instead of invented page numbers.
- The input lacks the context of “this effect.” The guide marks that explanation
  unresolved rather than attributing a complete scaling rationale to the author.
- Q/K/V and softmax definitions are marked background. The local reading path is
  marked inference and does not claim a map of the full paper or its results.
- Chinese explanations preserve original terminology. Coverage and missing
  material appear before the main thread; no prerequisite quiz was required.

An initial CUA attempt to open a local file was rejected by its URL policy.
No successful inspection was attributed to that attempt. The saved HTML bytes
were subsequently loaded into an isolated Edge page with Playwright `setContent`.
All **9 details controls toggled**, all **23 fragment targets existed**, a
directory click reached `#thread`, and a 390px viewport had no horizontal overflow.
Desktop and mobile screenshots were inspected during evaluation. This tests the
saved artifact's content and controls; it does not verify every browser's local
file-opening policy. Native controls require no network or JavaScript.

Reproduce the public renderer checks from the repository root:

```text
python -m unittest discover -s tests -v
python skills/paper-guide/scripts/render_guide.py examples/paper-guide/agent-invocation-zh.json --output <temporary-guide.html>
node tests/check_guide_browser.cjs <installed-playwright-module> <chromium-browser-executable> <temporary-guide.html>
```

The browser check is optional tooling, not a runtime dependency. The evaluator
used the bundled Playwright module and installed Edge; no project npm package
or browser download was required. The six Python CLI tests passed. Both skill
packages passed the skill-creator `quick_validate.py` validator. Python syntax
compilation passed; this repository has no static typechecker configuration.
Deterministic reference checks cannot verify factual accuracy, so they were
paired with the source review above.

## Tutor entrypoint and controls

A second independent agent read `skills/paper-tutor/SKILL.md` and the same
fixture, with the goal of understanding Attention output and Q/K/V. It did not
read a guide or require guide output. Selected actual turns are recorded in
[actual-session.md](../../examples/paper-tutor/actual-session.md).

Observed checks: one principal question per ordinary round; correct calculation
but mistaken identification of output received specific feedback; an explicit
“don't know” caused immediate worked teaching and a smaller prerequisite check;
the demonstrated prerequisite caused an explicit return to the original goal.
“懂了” did not establish mastery. Direct English explanation, concept-map,
pause, skip, changed target, resumed Chinese teaching, and end requests were
honored. Pausing/ending introduced no new question and did not create a progress
file or promise cross-session retention. The shortened source limitation was
preserved after changing targets to scaling. A second mixed answer received
separate credit for its correct numerical result and correction of its rule.
