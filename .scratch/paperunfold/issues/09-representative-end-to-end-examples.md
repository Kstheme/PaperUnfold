# 09: 发布跨论文类型的中英文导读与教学续学示例

**What to build:** 研究人员可以打开真实示例，核对导读效果，并看到从导读到教学、暂停和续学的完整使用过程。

**Blocked by:** 03 — 本地 PDF 生成全文或覆盖范围明确的导读; 05 — 按论文内容生成研究逻辑与必要图示; 06 — 从 HTML 导读复制提示词进入教学; 07 — 暂停后保存真实学习进度并跨会话续学.

**Status:** completed

**规格用户故事：** 44、46。

- [x] 选择全文可读取的算法论文、实证研究及理论或人文论证材料，各自提供真实生成的 HTML 与原文来源。
- [x] 示例记录材料覆盖范围、生成环境与输出语言，包含中文与英文输出，不将示例截图包装成尚未实现的能力。
- [x] 完成关键解释的原文对照评审，记录条件、不确定性、术语与位置核验结果；错误先修正再发布示例。
- [x] 提供简短教学片段，覆盖回答不完整、明确不知道、直接解释和退出，以及一条保存进度后续学的真实路径。
- [x] 示例操作从实际 skill 入口验收，页面打开、跳转、展开和复制提示词可用，教学与学习进度行为可核对。
- [x] 用相同原文材料展示普通文字解释与导读的差异，说明生成条件，不承诺未经测量的时间节省或掌握率。
- [x] 记录各类型案例的局限，示例覆盖不等于已经证明所有学科讲解质量。
