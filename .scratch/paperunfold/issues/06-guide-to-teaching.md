# 06: 从 HTML 导读复制提示词进入教学

**What to build:** 研究人员在导读中选择章节或术语，复制教学提示词到 Agent 对话后即可进入该目标的教学。

**Blocked by:** 01 — 粘贴原文生成首个轻量 HTML 导读; 02 — 从原文直接开展问题驱动教学.

**Status:** ready-for-agent

**规格用户故事：** 29。

- [ ] 章节和术语提供可复制教学提示词，包含论文来源、可核对的位置与学习目标。
- [ ] 复制提示词后，paper-tutor 能围绕指定目标开始；没有读取权限或源材料时明确提出需要的材料，不编造上下文。
- [ ] HTML 不承担模型调用，原文直接教学的独立入口仍然可用。
- [ ] 验证从保存的 HTML 复制章节与术语提示词、粘贴到实际 Agent 对话并获得相关首轮教学的完整路径。
- [ ] 复制行为在已声明的浏览器环境可用；有环境限制时提供清晰可用的文本复制方式。
