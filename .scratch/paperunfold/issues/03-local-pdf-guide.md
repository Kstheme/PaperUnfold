# 03: 本地 PDF 生成全文或覆盖范围明确的导读

**What to build:** 研究人员提供本地 PDF，即可获得章节导读与研究逻辑；文件不完整或无法读取时得到明确的覆盖与失败说明。

**Blocked by:** 01 — 粘贴原文生成首个轻量 HTML 导读.

**Status:** completed

**规格用户故事：** 3、7、8、12、13、14、19、20、25。

- [x] 使用已验证环境中的实际读取能力，从一篇可读的本地 PDF 生成 HTML 导读，记录必要依赖。
- [x] 可读全文具有全篇地图、各章作用与章节联系，解释从研究问题到结论的路径，背景按需补充。
- [x] 需要进一步分解方法时说明步骤的作用、条件、结果和联系；论证性材料按实际推理组织。
- [x] 原文证据位置来自实际读取的页、节或可定位片段，明确读取页码与原文页码存在差异的情况。
- [x] 对部分缺页、扫描识别不足和无法提取正文的输入如实报告；能解释部分材料时限制范围，完全不可读时不编造导读。
- [x] 验证正常 PDF 和至少一个不完整或不可读样例，检查实际来源覆盖、关键解释和保存页面的可用性。
