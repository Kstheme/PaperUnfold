# 08: 按需提供聚焦一个机制的小实验与静态替代

**What to build:** 研究人员请求机制交互或该交互确实有助理解时，可以操作变量观察变化；不能可靠生成时仍能获得可用的静态解释。

**Blocked by:** 05 — 按论文内容生成研究逻辑与必要图示.

**Status:** ready-for-agent

**规格用户故事：** 42、43。

- [ ] 围绕一个明确理解问题完成从原文、变量操作到解释结果的演示，讲清图中量、来源关系、教学假设与变量范围。
- [ ] 构造的教学数值和模拟结果清楚标注，不作为论文实验结果或复现证明。
- [ ] 基本导读可以先完成，不要求每篇论文生成小实验，也不以视频或动画作为必需输出。
- [ ] 无法可靠实现或环境不支持时提供静态图示或分步数值例子，不阻塞基本阅读。
- [ ] 以一个确有帮助的机制场景验证操作与解释，并以一个不适合或不可可靠生成的场景验证静态替代。
- [ ] 该增强不作为轻量版本发布的前置条件；未完成时发布文档不得宣称已具备机制交互支持。
