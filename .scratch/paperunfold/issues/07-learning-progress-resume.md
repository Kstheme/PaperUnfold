# 07: 暂停后保存真实学习进度并跨会话续学

**What to build:** 研究人员在章节结束或暂停时得到简短学习进度文件，在新对话中携带该记录和原文继续学习。

**Blocked by:** 02 — 从原文直接开展问题驱动教学.

**Status:** completed

**规格用户故事：** 40、41。

- [x] 章节结束或暂停时保存论文来源、当前学习位置、已讲解内容、具体回答支持的理解情况、未解决缺口与后续学习入口。
- [x] 区分“已讲解，未验证”和有回答依据的掌握情况；用户说懂了、看过导读或结束会话不自动升级状态。
- [x] 用当前理解状态选择续学起点，不在每轮完整展示进度文件，也不强制用户补齐全部缺口后才允许结束。
- [x] 新会话读取进度并结合可读原文继续指定问题；源材料缺失时明确限制，进度文件不代替论文证据。
- [x] 实际演示教学、暂停保存、新会话读取、继续学习的完整流程，并核对学习位置和未解决知识缺口没有丢失或被虚构。
