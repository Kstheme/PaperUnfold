# 01: 粘贴原文生成首个轻量 HTML 导读

**What to build:** 研究人员提供可读原文片段后，直接通过 paper-guide 得到可打开、可核对的单文件 HTML 导读。

**Blocked by:** None (can start immediately).

**Status:** completed

**规格用户故事：** 6、7、9、10、11、12、15、16、17、18、19、25、26、27、28。

- [x] 提供可实际调用的 paper-guide 入口，在至少一个真实 Agent 环境运行从输入到 HTML 的完整路径，记录环境与运行结果。
- [x] 导读先呈现可读材料的研究主线、已知章节作用、必需术语与原文证据位置；片段不足以支持全篇地图时明确覆盖范围。
- [x] 提供基本目录跳转、术语展开与内容折叠，保存后的页面可以打开并执行这些操作。
- [x] 讲解跟随对话语言，显式语言要求优先，关键术语保留原文名称；首次导读不要求基础知识测试或学科选择。
- [x] 保留选定原文中的数字、条件与不确定性，区分原文陈述、补充背景、推断与类比，不虚构原文位置。
- [x] 用一个真实片段完成调用与页面操作检查，并逐项对照原文核验关键解释；不把生成成功当作用户已经掌握。
