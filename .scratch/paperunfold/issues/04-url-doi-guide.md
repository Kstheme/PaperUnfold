# 04: 论文链接、网页与 DOI 定位到真实材料并生成导读

**What to build:** 研究人员给出论文链接、网页或 DOI 后，Agent 尝试取得实际可读材料并生成导读，无法取得全文时如实说明。

**Blocked by:** 03 — 本地 PDF 生成全文或覆盖范围明确的导读.

**Status:** ready-for-agent

**规格用户故事：** 4、5、7、8。

- [ ] 分别用可访问网页、在线论文 PDF 和 DOI 走通定位、读取、覆盖声明与 HTML 输出路径。
- [ ] 复用已经验证的 PDF 阅读行为；来源和证据位置与实际取得的版本一致。
- [ ] DOI、标题和元数据只用于定位，不作为已经取得全文的证明。
- [ ] 只取得摘要或片段时明确限定导读范围；全文不可访问时说明限制及继续所需的材料。
- [ ] 用可访问来源与至少一个不可访问全文的来源验证完整结果与失败行为，不为访问失败虚构论文内容。
