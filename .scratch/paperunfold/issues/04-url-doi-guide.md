# 04: 论文链接、网页与 DOI 定位到真实材料并生成导读

**What to build:** 研究人员给出论文链接、网页或 DOI 后，Agent 尝试取得实际可读材料并生成导读，无法取得全文时如实说明。

**Blocked by:** 03 — 本地 PDF 生成全文或覆盖范围明确的导读.

**Status:** done

**规格用户故事：** 4、5、7、8。

- [x] 分别用可访问网页、在线论文 PDF 和 DOI 走通定位、读取、覆盖声明与 HTML 输出路径。
- [x] 复用已经验证的 PDF 阅读行为；来源和证据位置与实际取得的版本一致。
- [x] DOI、标题和元数据只用于定位，不作为已经取得全文的证明。
- [x] 只取得摘要或片段时明确限定导读范围；全文不可访问时说明限制及继续所需的材料。
- [x] 用可访问来源与至少一个不可访问全文的来源验证完整结果与失败行为，不为访问失败虚构论文内容。

## 验收记录

见[04/05 实际调用与产物验收](../../../docs/validation/tickets-04-05.md)。网页、在线 PDF 与裸 DOI 分别取得真实材料后生成限定章节的导读；受限出版页面只取得摘要预览，保留部分覆盖声明和继续所需材料。该路线失败不代表所有合法版本均不可访问。HTTP 助手不执行网页脚本、不登录，也不提供 OCR。
