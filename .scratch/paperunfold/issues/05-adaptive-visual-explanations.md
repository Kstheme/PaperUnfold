# 05: 按论文内容生成研究逻辑与必要图示

**What to build:** 同一导读入口能为不同研究和论证方式选择合适的解释与图示，帮助研究人员理解真实机制、证据或推理。

**Blocked by:** 03 — 本地 PDF 生成全文或覆盖范围明确的导读.

**Status:** done

**规格用户故事：** 1、2、18、20、21、22、23、24、26、27。

- [x] 以实际论文内容决定结构，覆盖可执行方法、实证证据与理论或人文论证，不要求用户选择学科模板。
- [x] 执行方法解释步骤关系，理论或论证解释前提、论据、推理与结论，不把所有材料强制转换为输入输出或实验流程。
- [x] 按问题选用全篇地图、流程图、对照表、概念关系图或公式拆解，不强制每章生成图示。
- [x] 原文存在且有助于主线的图表和公式具有目的、读法及结论解释；没有相关内容时不生成空模块或虚构内容。
- [x] 教学图示、构造数值和类比与作者原有图表及实验结果能够区分；设计动机缺少依据时标明推断。
- [x] 同一论文在中文和英文讲解下保留一致概念、条件和可核对位置；主线保持简明，细节可以展开。
- [x] 用不同论证方式的可读材料实际生成并核验 HTML，在页面与原文对照中验证类型适配和语义保留。
